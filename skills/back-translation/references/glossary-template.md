# Translation glossary: <project>

Fixed term choices for translated pages. Vendor terms come from the vendor's own
localised help (terminology only, never facts).

## Register

- pt: você, Brazilian Portuguese.
- es: tú, neutral Latin American Spanish.

## UI labels

The app is English only, so its labels stay in English with a gloss in brackets the first
time.

| English label | pt gloss | es gloss |
|---|---|---|
| Save changes | salvar alterações | guardar cambios |

## Vendor terms

Confidence: high = two independent vendor pages agree; medium = one human-translated
vendor page; low = a machine-translated page, or no localised page (our choice). Low
terms are flagged to the translator and re-checked on the next run.

| English | pt | es | Source (URL, date read, MT/HT) | Confidence |
|---|---|---|---|---|
| Reset password (button) | Redefinir senha | Restablecer contraseña | https://vendor-a.example.com/pt-br/help/reset (2026-11-01, HT); https://vendor-b.example.com/es-es/docs/reset (2026-11-01, HT) | high |
| security baseline | linha de base de segurança | línea base de seguridad | https://vendor-b.example.com/pt-br/docs/baselines (2026-11-01, MT) | low |

Keep as written: product names, cmdlets, API names, file formats.
